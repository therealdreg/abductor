SWD debug of the CW312T-SAM4S THROUGH the Abductor (CW312->CW308 adapter) on the CW308 UFO.
Chain: Husky Plus MPSSE -> CW308 UFO -> Abductor -> CW312T-SAM4S.
This exercises the Abductor's JTAG/SWD debug routing (JTAG_TMS / JTAG_TCK).

Setup (non-DIO MPSSE, enable_MPSSE(1)); the Husky drives SWD on the main 20-pin SPI/PDI pins.
Bridge on the CW308 UFO (4 wires), the same signals JP3 bridges on the CW313:
  UFO SCK   -> J8 J_TCK  (JTAG_TCK = SWCLK)
  UFO PDID  -> J8 J_TMS  (JTAG_TMS = SWDIO)
  UFO VREF  -> J8 J_UREF (JTAG_VREF; powers the 100k JTAG pull-ups, which the UFO does not drive)
  UFO nRST  -> J8 J_TRST (CW reset line jumpered to the JTAG_TRST pin)
GND is already common through the main 20-pin ribbon, so no separate ground wire is needed.
The SAM4S JTAG then reaches the CPU via: J8 -> UFO target socket -> Abductor -> CW312 edge -> SAM4S.
Husky Plus USB PID 0xace6. Transport: SWD @ 400 kHz. OpenOCD 0.12.0.
