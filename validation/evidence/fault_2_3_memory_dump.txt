fault101 Fault 2_3 - Voltage Glitching to Memory Dump  (official ChipWhisperer fault101 lab)
Target: CW312T-SAM4S via Abductor + CW308 UFO, ChipWhisperer Husky Plus (crowbar on UFO VOUT)
Firmware: bootloader-glitch. Attack: glitch the send-loop bound `for(i=0;i<ascii_idx;i++)putch`
so the target sends PAST its 8-byte ack, dumping the adjacent decrypted data_buffer / RAM.
Glitch: high-power crowbar, width=2000, offset=2480, ext_offset=2122 (send-loop, trig_count=2159).
Normal response = 8 bytes ('r0' + newlines).  Glitched response = 601 bytes (this dump).
Success is rare (about 1 in ~2100 attempts): the glitch must hit the last bound-check instant.
